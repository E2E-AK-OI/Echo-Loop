# Alibaba Cloud Model Studio:Qwen-Audio-TTS server-side events

## task-started

After the client sends the `run-task` command, the server returns a `task-started` event to signal that the task has started. The client can send subsequent commands only after receiving this event.

`run-task`
`task-started`

|  |  |
| --- | --- |
| **header.task\_id** `string`  The task ID generated by the client.  **header.event** `string`  Event type. Fixed value: `task-started`.  **payload** `object`  Empty object. | ``` {   "header": {     "task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",     "event": "task-started",     "attributes": {}   },   "payload": {} }  ``` |

**header.task\_id** `string`

`string`

The task ID generated by the client.

**header.event** `string`

`string`

Event type. Fixed value: `task-started`.

`task-started`

**payload** `object`

`object`

Empty object.

`{
"header": {
"task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",

},

}`

## result-generated

After the client sends text, the server continuously returns `result-generated` events. Each event carries sentence-level metadata.

`result-generated`

|  |  |
| --- | --- |
| **header.task\_id** `string`  The task ID generated by the client.  **header.event** `string`  Event type. Fixed value: `result-generated`.  **payload.output** `object`  Output information.  Properties  **type** `string`  Sub-event type. Valid values:   * `sentence-begin`: Sentence start. Returns the text to be synthesized. * `sentence-synthesis`: Marks an audio frame. One audio frame is transmitted over the WebSocket binary channel immediately after each event. * `sentence-end`: Sentence end. Returns the text content and usage information (`usage`).   **sentence.index** `integer`  Sentence index, starting from 0.  **sentence.words** `array`  Word-level timestamp array.  words element properties  **text** `string`  Text content of the word.  **begin\_index** `integer`  Start character index of the word within the sentence. Starts at 0.  **end\_index** `integer`  End character index of the word within the sentence. Starts at 1.  **begin\_time** `integer`  Start time of the word's corresponding audio, in milliseconds.  **end\_time** `integer`  End time of the word's corresponding audio, in milliseconds.  **original\_text** `string`  Text of the sentence as segmented for synthesis.  **payload.usage** `object`  Billing usage, returned in the `sentence-end` event.  **Note**`qwen-audio-3.1-tts-flash` is billed by input and output Tokens. `qwen-audio-3.1-tts-plus`, `qwen-audio-3.0-tts-plus`, and `qwen-audio-3.0-tts-flash` are billed by character.  Properties  **input\_tokens** `integer`  Input token count for this request.  **Note**Applies to `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`.  **output\_tokens** `integer`  Output token count for this request.  **Note**Applies to `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`.  **total\_tokens** `integer`  Sum of input and output tokens.  **Note**Applies to `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`.  **characters** `integer`  Cumulative number of billed characters. | sentence-begin ``` {   "header": {     "task_id": "3f2d5c86-0550-45c0-801f-xxxxxxxxxx",     "event": "result-generated",     "attributes": {}   },   "payload": {     "output": {       "sentence": {         "index": 0,         "words": []       },       "type": "sentence-begin",       "original_text": "Before my bed, moonlight shines bright,"     }   } }  ``` sentence-synthesis ``` {     "header": {         "task_id": "3f2d5c86-0550-45c0-801f-xxxxxxxxxx",         "event": "result-generated",         "attributes": {}     },     "payload": {         "output": {             "sentence": {                 "index": 0,                 "words": []             },             "type": "sentence-synthesis"         }     } }  ``` sentence-end ``` {   "header": {     "task_id": "3f2d5c86-0550-45c0-801f-xxxxxxxxxx",     "event": "result-generated",     "attributes": {}   },   "payload": {     "output": {       "sentence": {         "index": 0,         "words": [           {             "text": "Before",             "begin_index": 0,             "end_index": 1,             "begin_time": 0,             "end_time": 263           }         ]       },       "type": "sentence-end",       "original_text": "Before my bed, moonlight shines bright,"     },     "usage": {       "characters": 6     }   } }  ``` |

## task-finished

The server returns a `task-finished` event when the task completes. The client can then close the WebSocket connection or reuse it to start a new task.

`task-finished`

|  |  |
| --- | --- |
| **header.task\_id** `string`  The task ID generated by the client.  **header.event** `string`  Event type. Fixed value: `task-finished`.  **payload.usage** `object`  The fields are the same as [usage in result-generated](#usage-fields). | ``` {   "header": {     "task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",     "event": "task-finished",     "attributes": {       "request_uuid": "0a9dba9e-d3a6-45a4-be6d-xxxxxxxxxxxx"     }   },   "payload": {     "usage": {       "characters": 13     }   } }  ``` |

**header.task\_id** `string`

`string`

The task ID generated by the client.

**header.event** `string`

`string`

Event type. Fixed value: `task-finished`.

`task-finished`

**payload.usage** `object`

`object`

The fields are the same as [usage in result-generated](#usage-fields).

`{
"header": {
"task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",
"event": "task-finished",
"attributes": {
"request_uuid": "0a9dba9e-d3a6-45a4-be6d-xxxxxxxxxxxx"
}
},
"payload": {
"usage": {
"characters": 13
}
}
}`

## task-failed

The server returns a `task-failed` event when the task fails. On receiving this event, the client must close the WebSocket connection and handle the error.

`task-failed`

|  |  |
| --- | --- |
| **header.task\_id** `string`  The task ID generated by the client.  **header.event** `string`  Event type. Fixed value: `task-failed`.  **header.error\_code** `string`  Error code.  **header.error\_message** `string`  Detailed error message. | ``` {   "header": {     "task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",     "event": "task-failed",     "error_code": "InvalidParameter",     "error_message": "[tts:]Engine return error code: 418",     "attributes": {}   },   "payload": {} }  ``` |

**header.task\_id** `string`

`string`

The task ID generated by the client.

**header.event** `string`

`string`

Event type. Fixed value: `task-failed`.

`task-failed`

`string`

Error code.

**header.error\_message** `string`

`string`
